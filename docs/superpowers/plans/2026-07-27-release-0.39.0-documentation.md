# AgentsView 0.39.0 Documentation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use
> superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use
> checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish implementation-accurate 0.39.0 release documentation, one
reproducible semantic-search setup screenshot, complete contributor credits, and
a review-ready pull request.

**Architecture:** Treat merged source and tests in `v0.38.1..v0.39.0` as the
technical source of truth and the user-provided release summary as the editorial
baseline. Keep mature features discoverable across overview and focused guides,
correct experimental Recall without promoting it, and publish generated image
media through the existing orphan asset branch before docs source references it.

**Tech Stack:** Markdown/Zensical, Bash asset manifests, Go/testify asset tests,
Playwright/TypeScript screenshot automation, Docker screenshot generation, Git,
and GitHub CLI.

## Global Constraints

- Work inline on the existing `0.39.0-docs` branch; do not create or switch
  branches.
- Keep Recall and the artifact foundation explicitly experimental and low-key.
- Describe the artifact work as wire/store foundation only; there is no
  export/import, transport, server, database, or CLI integration in 0.39.0.
- Preserve private-data hygiene in docs, fixtures, screenshots, commits, and PR
  text.
- Keep generated PNG media off the feature branch and publish it through
  `docs-generated-assets` before validating docs that reference it.
- Do not merge the pull request.
